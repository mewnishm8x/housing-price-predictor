# 🏠 Housing Price Prediction App

## 📌 Overview
This project is a machine learning application that predicts house prices based on property features such as area, bedrooms, bathrooms, and furnishing status.

A Random Forest Regression model is trained on real housing market data and deployed using a Streamlit web app.

---

## 🧠 Machine Learning Model
- Algorithm: Random Forest Regressor
- Task: Regression
- Target: House Price

---

## 📊 Features Used
- Area (sq ft)
- Number of bedrooms
- Number of bathrooms
- Number of stories
- Main road access
- Furnishing status

---

## 🌐 Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- JupyterLab
- GitHub
